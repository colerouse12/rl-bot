# Project reference lookup
Use `$rl-bot-docs` when available for version-aware documentation lookup.
If the skill is not installed, follow this short fallback:
Read docs/README.md, then the relevant docs/project/ note.
Use docs/REFERENCES.md to locate official documentation for the exact topic.
Search installed source for the exact symbol or error before reading long files.
Inspect installed package source when behavior is unclear. Browse official sources
only for missing, stale, conflicting, or explicitly current facts; record verified
answers and applicable versions locally. Never infer runtime success from docs.
Keep verified project conclusions in the owning project note. Read relevant sections,
not entire sites or packages. Keep binaries, environments, checkpoints and logs out of
ordinary searches. Do not commit or push unless asked.
